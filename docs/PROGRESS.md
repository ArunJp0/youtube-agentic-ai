## Known Limitations

- Visual semantic relevance is still limited by deterministic (non-LLM) query generation and by what stock footage is actually available from Pexels for a given query - some selected clips are only loosely related to the narration they accompany. This is a content-quality limitation, not a pipeline defect: the pipeline still reliably produces a complete, correctly-timed, playable video. A future QC/visual-relevance-validation step could reject weak asset matches and request alternatives, but is not implemented yet.
- For long videos where Pexels lacks enough unique matching stock footage, controlled asset reuse (and, as a last resort, looping) remains an accepted fallback rather than a hard failure.
